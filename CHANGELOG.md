# Changelog

## 1.0.0
First public release.

- Content-Type Builder with presets, real tables per type, Strapi-style REST API, roles/permissions matrix, API tokens, webhooks.
- Content Manager with draft/publish and per-entry visual designer (layers, Flex/Grid, breakpoints, hover, field binding, context menu).
- Frontend importer: zip/HTML upload, view assignment, click-to-bind mapper (text, HTML, attributes, background, repeat, menus, forms), JS page capture, design-system inheritance.
- Blocks library with custom fields, editable through the preview & bind screen.
- Arabic/English admin and an independent site language with `lang`/`dir` injection.
- New sign-in page, password recovery by email link, factory reset from Settings.
- IBM Carbon structure with brand colors (#221cfc / #0a0178), IBM Plex Sans Arabic, Hugeicons.
